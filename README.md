## 2. Data Siswa

**File:** `01-javascript-fundamentals/02-data-siswa/index.js`

### Fitur
- Menampilkan semua data siswa
- Filter data siswa yang lulus (nilai >= 80)
- Mencari siswa berdasarkan nama
- Menampilkan nama, nilai, dan umur
- Menampilkan daftar nilai saja
- Menjumlahkan nilai
- Menampilkan daftar nama siswa yang lulus
- Menghitung nilai rata-rata
- Mencari siswa dengan nilai tertinggi
- Mencari siswa dengan nilai terendah

### Contoh Penggunaan
```bash
node index.js
```
